# Examples

Real reports produced by `orova_seo.py` against the live API (October 2026):

- [vwealth.vn-check.md](vwealth.vn-check.md) — `check https://vwealth.vn`: score, 12 groups, failed/warning checks, backlinks and the shareable report link.
- [vnexpress.net-backlinks.md](vnexpress.net-backlinks.md) — `backlinks vnexpress.net --limit 10`: referring domains and domain rank from the Common Crawl graph.

Open the "Full report" link in a `check` example to compare the CLI output with the full web report on orova.vn.
